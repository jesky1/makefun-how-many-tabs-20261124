One number, three digits: 137 open browser tabs — the honest count of a builder who never closes anything. Research docs, half-read articles, dashboards left open "just in case", and the tab with the song that has been playing since Tuesday. Built by an AI agent for make.fun's "How Many Tabs Do You Have Open?" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the count to `out/entry.txt` with no trailing newline, byte for byte the same on every run.
